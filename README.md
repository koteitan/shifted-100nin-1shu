**原歌**: 村雨の 露もまだひぬ 槙の葉に 霧立ちのぼる 秋の夕暮

**変歌**: 夢の友　目にぞ思ひ出づ　櫓より　髪を思へば　夢にしぞある

**意味**: 夢の中で逢った友よ――その面影がふと目に思い出される。高く立つ櫓のあたり、垂れる髪のことに想いを馳せれば、それすらもまた夢の中にあったことなのだ。原歌が「村雨の露が槙の葉に残るうちから霧が立ちのぼる秋の夕暮」という外景の無常を歌ったのに対し、+1変換は「雨→目」「霧→思い出す」「夕→夢」「村→友」「槙→櫓」「ぬ→髪」と異言語の語へと化けたため、自然描写から「夢の中の友を追想する」内面の哀感へと変容した。許された語彙(夢・友・目・思ひ出づ・櫓・髪)だけで再構成し、寂蓮法師の寂寥は「夢の中の追憶」という形で響き合う。
